# Farm Helper

Bug reports and suggestions for **Farm Helper**, a Farming Simulator 25 mod by MinasByte Mods.

This repository exists only for feedback. The source code of the mod is not hosted here.

## How to help

**[Open a bug report or a suggestion](https://github.com/MinasByte-Mods/FS25_FarmHelper/issues/new/choose)**

You can write in English or Portuguese. Before opening a new issue:

1. Search the [existing issues](https://github.com/MinasByte-Mods/FS25_FarmHelper/issues) to see if it was already reported.
2. Make sure you are using the latest version of the mod.
3. If you can, try again with Farm Helper as the only active mod.

## Attaching your log

The log file is the most useful thing you can send with a bug report. It is overwritten every time the game starts, so copy it right after the problem happens, before opening the game again.

```
Documents\My Games\FarmingSimulator2025\log.txt
```

The log can show your Windows user name inside file paths. You can replace it before attaching the file.

## About the mod

Farm Helper replaces the generic helpers with hired workers. Each one has a name, a portrait, skills and a working day of their own. You hire them, give them work, pay them and talk to them on the phone.

- Singleplayer only.
- Languages: English, German, Spanish and Brazilian Portuguese.
